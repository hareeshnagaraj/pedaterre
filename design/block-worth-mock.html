Sources & verification

This product started from the public NYC DOF property assessment dump (every tax lot, owner as filed, and market value) — the same release that circulated widely in July 2026. We do not invent sale prices. Towers, thermal area, ranks, and “$50M club” stats are all derived fields from the assessment roll.

  • Primary · NYC Department of Finance FY property assessment roll (final / supplemental as published) — market value, BBL, building class, owner name as filed. Property assessments page · download zips by tax class (e.g. FY27 fy27_avroll1234.zip and class files linked there).
  • Machine-readable · NYC Open Data Property Valuation and Assessment Data (tax classes 1, 2, 3, 4) — DOF as dataset owner. Open Data dataset 8y4t-faws · related assessment dataset yjxr-fw8i
  • Lookups · official city tools Property Information Portal (parcel map / assessment) · Geosearch for address → BBL via NYC Planning Labs GeoSearch when wired in production.
