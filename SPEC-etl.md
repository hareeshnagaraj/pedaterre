## Rules (all have named tests)
1. **R0 pointers**: rows with bldg_class=='R0' AND curmkttot==0 are
   excluded from lots/totals but recorded in the block's `lotToGroup` map
   by address (they are condo billing lots GeoSearch returns).
2. **Grouping**: lots >= 1001 with non-blank housenum_lo AND street_name
   group by (boro, block, LOW(housenum_lo), street_name) where LOW =
   leading integer of a range ("41-53" → "41"). Blank key component →
   lot stands alone. Multi-lot group with disagreeing owners → no owner
   label (omit field).
3. **Owner repair (E-1)**: owners are two 40-char fixed-width fields
   concatenated. If len>41 and char[40]==' ' and both fragments are
   non-space-adjacent and the left doesn't end in a standalone connective
   (' AND',' OF',' THE','&'): rejoin as a+b (drop the space). Payload
   `owner` = repaired; also emit `ownerRaw` ONLY when repair changed it.
   (make-fixtures.py `repair_owner` is the reference.)
4. **parid uniqueness ASSERTION** — duplicate parid = hard build failure.
5. **Tail rule**: >120 groups → keep club-containing groups + top by value
   to 119, fold rest into one `other` group. (Reference implementation.)
6. **club** flag = group CONTAINS a raw lot with mv > 50e6 (never by
   combined value). **zero** flag = group total is 0 (renders hatched).
7. **character** per block: empty (total<=0) | single (1 group) | whale
   (largest/total >= 0.32) | flat (max/min positive group values < 3) |
   spread (else). Reference implementation decides ties.
8. **Finiteness**: assert no NaN/Infinity anywhere; whaleShare guard for
   zero totals (largestGroupShare = null when total<=0).
9. **llcShare**: sum(mv of lots whose OWNER matches entity regex) /
   block total (0 when total<=0). Regex, case-insensitive, word-boundary:
   `\b(LLC|L\.L\.C\.|LP|L\.P\.|LLP|CORP|CORPORATION|INC|INCORPORATED|TRUST|HOLDINGS|PARTNERS|REALTY|PROPERTIES)\b`
10. **Ranks**: rank = dense rank of block totals desc over ALL 28,798
    blocks; percentile = rank/nBlocks*100 rounded to 1dp. rankTaxable =
    same over the taxable universe: blocks where
    sum(curactextot)/sum(curacttot) < 0.5 (guard div0 → treat as exempt).
11. **Quips**: deterministic templates by character (fill computed values,
    round percents to whole numbers; dry municipal register, no emoji):
    - whale, share>=45%: `One building is {p}% of the block's assessed value. Everyone else is a row house in its shadow.`
    - whale, share<45%: `The largest holding here carries {p}% of the block.`
    - spread with club: `{n} of {g} property groups on this block clear $50M.`
    - spread, no club: `{g} property groups. The top one is {m}× the median holding here.`
    - flat: `No towers here — {g} holdings within {x}× of each other. The roll calls that balance.`
    - single: `One lot. The whole block. One line in the roll.`
    - empty: `No assessed market value on this roll.`
